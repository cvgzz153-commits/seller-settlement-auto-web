# 셀러 정산 자동화 툴 · 무료 베타

주문서와 입금 내역의 첫 번째 엑셀 시트를 **사용자의 브라우저 안에서만** 대조하는 정적 웹 앱입니다. 업로드한 파일은 이 앱의 서버로 전송하거나 저장하지 않습니다.

## 베타 기능

| 기능 | 내용 |
|---|---|
| 유연한 열 인식 | `주문자명`, `구매자`, `주문금액`, `입금금액`, `연락처`, `주문번호` 등 자주 쓰는 열 이름을 자동으로 찾습니다. |
| 단계별 매칭 | 금액이 같은 거래를 기준으로 `주문번호 → 연락처 뒷자리 → 이름` 순으로 대조합니다. |
| 중복 방지 | 동일한 입금 기록은 한 건의 주문에만 매칭합니다. |
| 확인 필요 명단 | 일치하지 않는 주문을 엑셀 파일로 내려받을 수 있습니다. |
| 피드백 수집 | 앱의 **베타 피드백 남기기** 버튼으로 GitHub 이슈 작성 페이지를 엽니다. |

> 피드백에는 실제 주문 정보, 전화번호, 고객 실명 등 개인정보를 쓰지 마세요. 실제 유료 서비스 운영 전에는 주문번호 기반 매칭, 사용자 계정, 개인정보 처리 정책을 별도로 구현해야 합니다.


## 상용 서비스 전환 기반

Vercel 배포를 위한 `vercel.json`, 결제 서버리스 API 뼈대(`api/`), `.env.example`, 문의 버튼이 포함되어 있습니다. 실제 결제 키는 저장소에 넣지 않고 Vercel의 환경 변수로만 설정해야 하며, 결제 승인 API는 `PAYMENTS_LIVE_ENABLED=true`를 명시하기 전까지 비활성화됩니다.

| 경로 | 역할 |
|---|---|
| `api/payments/create-order.js` | 서버가 요금제·금액·주문번호를 생성합니다. |
| `api/payments/confirm.js` | 토스페이먼츠 시크릿 키를 서버 측에서만 사용해 결제를 승인합니다. |
| `api/webhooks/toss.js` | 비동기 결제 상태 수신을 위한 웹훅 엔드포인트입니다. |
| `.env.example` | Vercel에 등록할 환경 변수 이름과 설명입니다. |
| `COMMERCIAL_DEPLOYMENT_GUIDE.md` | GitHub 연동 CI/CD, 환경 변수, 결제 운영 전 체크리스트입니다. |

실제 유료 운영 전에는 사용자 인증과 영속 주문 저장소를 추가해, 서버가 주문 금액과 이용 권한을 재검증하도록 확장해야 합니다.


## 구독형 SaaS 모듈

기존 **입금 정산** 로직은 유지하며, 추가 기능은 배송·알림 및 매출 리포트 탭에 독립 모듈로 배치했습니다. 무료 사용자는 세 번의 로컬 정산을 실행할 수 있고, 이후 정산·자동 알림·고급 리포트는 Pro 구독 안내로 연결됩니다. 이 UI 잠금은 베타 검증용이며, 운영에서는 반드시 서버의 로그인·구독 데이터베이스를 기준으로 권한을 재검증해야 합니다.

| 모듈 | 위치 | 현재 구현 | 운영 전 추가 필요 사항 |
|---|---|---|---|
| 자동 알림 | 배송·알림 탭 및 `api/notifications/create-job.js` | 수신자 검증, 템플릿 렌더링, Pro 권한·공급자 활성화 게이트 | 알림톡/SMS 공급자 계약, 승인 템플릿, 수신 동의·발송 이력 DB |
| 수익 분석 | 매출 리포트 탭 | 브라우저 내 실제 정산 실행 기록으로 기간 매출·추정 순수익·미수금·완료율·추이 표시 | 계정별 영속 데이터, 원가·수수료·환불 데이터 모델 |
| Pro 페이월 | 두 탭의 고급 기능 진입점 | 기능별 구독 안내 모달과 주문 생성 API 연결 준비 | 인증, 구독 상태 DB, 토스페이먼츠 결제창·승인·웹훅 연결 |
